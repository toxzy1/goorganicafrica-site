GOA TOKEN 0 ENDO cultivo bem sucedido de cogumelos de ostra segue um processo consistente de cinco estágios. Entender cada etapa — e os requisitos críticos de higiene e gestão em cada etapa — é a diferença entre rendimentos elevados consistentes e perdas de contaminação. GOA TOKEN 1 FIM

GOA TOKEN 0 ENDStage 1 — Preparação do substratoGOA TOKEN 1 END

GOA TOKEN 0 ENDO substrato é o meio de cultivo que alimenta o cogumelo — é o equivalente do solo na cultura. Para cogumelos de ostras na Nigéria, o substrato padrão é uma combinação de serragem de madeira envelhecida (a principal fonte de carbono), casca de arroz (para aeração e drenagem), e um suplemento nutricional, como bolo de palmiste (PKC) ou farinha de milho (para aumentar o teor de proteína e rendimento). GOA TOKEN 0 ENDA nota crítica sobre o carbonato de cálcio: apenas cal agrícola (carbonato de cálcio, CaCO3) deve ser usado — nunca construir cal (cal hidratada ou cal rápida), que queima a pele em contato e mata micélio de cogumelos instantaneamente. Estes materiais parecem semelhantes, mas têm propriedades químicas completamente diferentes. O carbonato de cálcio é macio, suave e não queima a pele. GOA TOKEN 1 FIM

GOA TOKEN 0 ENDMixe cuidadosamente os materiais secos, em seguida, adicione água gradualmente enquanto testa o teor de umidade. O nível de umidade correto é confirmado pelo teste de aperto: pegue um punhado de substrato misto e aperte firmemente — se algumas gotas de água escorrerem, a umidade está correta. Se a água flui livremente, está muito molhada. Se o punhado se desmorona, está muito seco. GOA TOKEN 1 FIM

GOA TOKEN 0 ENDStage 2 — Ensacando o SubstrateGOA TOKEN 1 END

GOA TOKEN 0 ENDEmpacote o substrato umedecido em sacos de politeno resistentes ao calor (1-2 kg por saco), comprimindo suavemente sem empacotar muito firmemente. Amarre com segurança a boca de cada saco com um elástico. Sacos que são muito frouxamente embalados terão pobre crescimento de micélio; sacos embalados muito firmemente podem não permitir uma troca de ar adequada durante a incubação. GOA TOKEN 1 FIM

GOA TOKEN 0 ENDStage 3 — Pasteurização (esterilização)GOA TOKEN 1 END

GOA TOKEN 0 ENDPasteurização mata microrganismos prejudiciais concorrentes — bactérias, moldes e outros fungos — que de outra forma competiriam com o micélio do cogumelo e contaminariam os sacos. É uma das etapas mais críticas em todo o processo. Saltar ou pasteurização inadequada é a principal causa de perdas de contaminação entre os novos produtores de cogumelos. GOA TOKEN 1 FIM

GOA TOKEN 0 ENDO método de pequena escala nigeriano usa um tambor de metal em uma lenha ou fogo a gás. Os sacos de substrato são colocados numa plataforma de madeira ou metal levantada dentro do tambor — não devem sentar - se diretamente na água, visto que o vapor (não água fervente) é o que pasteuriza os sacos. O tempo de cozedura é de 6 horas com lenha ou 4 horas com gás. Após cozinhar, deixe os sacos esfriar completamente (o que pode levar 10-12 horas) antes de iniciar a inoculação. Inocular sacos quentes mata a desova. GOA TOKEN 1 FIM

GOA TOKEN 0 ENDStage 5 — IncubaçãoGOA TOKEN 1 END

GOA TOKEN 0 ENDApós inoculação, os sacos são colocados em uma sala de incubação escura e limpa a 25-30°C. Não é necessário regar durante a incubação. Dentro de 10 a 21 dias, micélio branco (rede raiz do cogumelo) deve colonizar totalmente o saco de substrato, tornando a mistura de serragem escura uniformemente branca. GOA TOKEN 1 FIM

GOA TOKEN 0 ENDContaminação deve ser monitorada cuidadosamente durante esta fase. Remova qualquer saco mostrando coloração verde, preta ou amarela persistente imediatamente — estes indicam contaminação por Aspergillus niger, Trichoderma ou outros moldes concorrentes que podem se espalhar para sacos adjacentes. A única resposta segura à contaminação é a retirada imediata do saco afetado da sala de incubação. GOA TOKEN 1 FIM

GOA TOKEN 0 ENDStage 6 — Frutificação e colheita GOA TOKEN 1 END

GOA TOKEN 0 ENDQuando os sacos estão totalmente colonizados, movê-los para a sala de frutificação. Corte pequenos buracos nas laterais dos sacos para permitir que cogumelos emerjam. Manter a umidade na sala de frutificação, pulverizando água nas paredes e no chão (não diretamente em cogumelos). Assegurar boa ventilação e luz indireta. GOA TOKEN 1 FIM

GOA TOKEN 0 ENDEm boas condições, cogumelos começam a aparecer dentro de 3-7 dias após se mudarem para a sala de frutificação. Colhe quando as tampas estiverem totalmente formadas e as bordas ligeiramente enroladas — torça ou corte suavemente, em vez de puxar com força. Um único saco normalmente produz 3 descargas durante 4-6 semanas antes do substrato ser esgotado. O rendimento total é tipicamente de 600g-1kg de cogumelos frescos por saco de substrato de 1 kg em todos os flushes. GOA TOKEN 1 FIM
