# GoOrganicAfrica — Production Website

GoOrganicAfrica is an Eleventy-powered agricultural education and farm-profit calculator site for Africa.

## Included
- CMS-managed calculator countries with an expansion path toward all 54 African countries
- 17 calculator enterprises/commodities
- Blog with four unique featured images
- Ebooks and Selar links
- SEO, canonical URLs, structured data and sitemap
- About, Contact and Privacy pages
- GitHub/Decap CMS
- Review-first agricultural-data monitoring architecture
- Seed-price data architecture and manual override
- Android-friendly CMS route at `/admin/`
- Review-first agricultural directory monitoring for Finance, Grants and Machinery
- Master CMS/project specification in `PROJECT-MASTER-SPEC.md`

See `ADMIN-SETUP.md` and `DEPLOY.md` before deployment.
